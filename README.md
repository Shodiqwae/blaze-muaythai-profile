# 🔥 Blaze Muaythai — Private Door-to-Door Personal Training

> Official Web Landing Page & Booking Portal for **Blaze Muaythai** by **Coach Usep**.  
> Exclusive door-to-door Muay Thai & Martial Arts training in **Jakarta Selatan & Kota Depok**.

---

## 🥊 Fitur Utama

- **Door-to-Door Private Service**: Coach datang langsung ke rumah, apartemen, taman kompleks, atau private gym.
- **Pilihan Sesi (1 & 2 Orang / Duo)**:
  - 1 Orang: Single Session (Rp 350.000) & Paket Komitmen 10 Sesi (Rp 3.000.000 — Hemat 500k).
  - 2 Orang (Duo): Single Session (Rp 500.000 / 250k per org) & Paket Komitmen 10 Sesi Duo (Rp 4.500.000 — Hemat 500k / 225k per org).
- **Durasi Sesi Fleksibel**: 60 Menit (1 Jam) hingga 90 Menit (1J 30M).
- **Struktur Latihan Otentik 5 Tahap**: Pemanasan Dinamis & Mobility, Shadow Boxing & Drill Teknik, Pad Work Intensif, Core & Conditioning, Cooling Down & Evaluasi.
- **Kalkulator Kalori Interaktif**: Estimasi pembakaran kalori akurat berdasarkan berat badan dan durasi latihan.
- **Formulir Booking WhatsApp Terintegrasi**: Direct booking ke WhatsApp resmi Coach Usep (+62 896-8054-4568).
- **Desain Modern Dark Mode**: Red & Black aesthetic dengan Tailwind CSS v4, Lucide Icons, dan mobile-first UI.

---

## 🛠️ Tech Stack

- **Framework**: [React.js](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: Vercel / Netlify / GitHub Pages compatible

---

## 🚀 Memulai (Development)

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Jalankan Development Server**:
   ```bash
   npm run dev
   ```

3. **Build untuk Produksi**:
   ```bash
   npm run build
   ```

4. **Preview Build**:
   ```bash
   npm run preview
   ```
